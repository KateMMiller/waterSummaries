# waterSummaries
This repo contains scripts and R markdown reports that generate a tabbed html summarizing water quality and quantity by park, 
site type (eg lake or stream), site, and parameter type (eg, water quality or quantity, field vs. lab measurements). 

Notes on this repo: 
<ul>
<li>You must have the waterNETN R package installed to run this code `pak::pkg_install('doi-nps/waterNETN')`</li>
<li>The climateNETN package is also required to generate figures in the water quantity sections of the report. `pak::pkg_install('doi-nps/climateNETN')`</li>
<li>The git page associated with this repo is generated by the index.rmd markdown report. This must be rendered
to produce an index.html file, which is then deployed as the git page.</li>
<li>The index.Rmd requires a zip file of the latest data package be saved in a data folder in this repo.</li>
<li>The index.Rmd depends on the following files: </li>
  <ul>
  <li>ACAD_summary.rmd: report for ACAD sites. Can be run stand alone to troubleshoot, but have to uncomment lines 46-47, 
setting yr_current and yr_start parameters.</li>
  <li>LNETN_summary.rmd: report for non-NETN parks. Currently hard coded to start at 2006 and end in 2024, when monitoring
in LNETN parks ended. This can be run for an individual park to troubleshoot by changing the params in the YAML at the top. 
The index.rmd runs through a list of NETN parks to generate the tabbed report for each LNETN park. </li>
  <li>plotting_functions.R: contains plotting functions used several places in ACAD and LNETN reports.</li>
  <li>fake_bands_legend_code.R: creates a better formatted legend for the current vs. historic water bands plots.</li>
  <li>www/: folder contains general formatting files, like the CSS, the front page photo, and the arrowhead, which is not on git. </li>
  <li>About_tabs.Rmd: contains information about the monitoring program, sites, and parameters sampled.</li>
  <li>header_manual.html: code for the NPS banner used as the report header. When report is no longer draft, remove that from this html.</li>
  <li>footer.html: code for the report footer that includes the month and year rendered. </li>
  <li>boundboxes.csv: sets bounding boxes for the leaflet site maps in the About the Sites tab.</li>
</ul>
</ul>
